## 🌟 Key Features

- 🎁 **Interactive 3D Surprise Unboxing**: Opens with a floating gift box that bursts into confetti, jingle bells SFX, and reveals a glassmorphism 3D greeting card.
- 💌 **Typewriter Greeting Letter**: Warm holiday wishes revealed character-by-character with random preset cycling and custom editing.
- ❄️ **60 FPS Canvas Snowfall Engine**: Physics-driven snowflakes swaying with pointer movement, featuring a toggleable **Arctic Blizzard Mode (❄️)**.
- 🌐 **Automatic Browser Language Detection**: Automatically displays in Vietnamese or English based on user locale, with an instant toggle button.
- 🎶 **Festive Vinyl Record Player**: Rotating holiday vinyl dock with music controls and smooth playback.
- 🎨 **Card Personalizer & Smart Shareable URL**: Customize recipient name, sender, avatar, and social links, generating a shareable URL (`?name=...&msg=...`).
- ⏰ **Live Christmas Countdown**: Counts down real-time to Christmas Eve (December 24th).
- 📱 **100% Responsive Design**: Flawless experience across phones, tablets, and desktops.

## 🚀 Getting Started & Deployment

### 1. Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Dungauto/thiepgiangsinh.git
   ```
2. Open `index.html` in your web browser.

---

### 2. Free Deployment with GitHub Pages
1. Push code to your GitHub repository.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select **`main`** and **`/ (root)`**, then click **Save**.
4. Website will be online at:
   ```
   https://<username>.github.io/thiepgiangsinh/
   ```

## 💌 URL Share Parameters

| Parameter | Description | Example |
| :--- | :--- | :--- |
| `name` | Recipient name | `?name=Emma` |
| `from` | Sender name | `&from=Santa` |
| `msg` | Dedicated message | `&msg=Merry%20Christmas!` |
| `lang` | Language code (`en` or `vi`) | `&lang=en` |
